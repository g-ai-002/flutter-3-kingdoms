# 三国霸业 🏯

基于 Flutter + Flame 的回合制三国争霸游戏，支持 Android、Windows 与 Web。择一方势力起兵，经营城池、登用名将、出征攻城，最终一统山河。全程单机离线，音效与背景音乐在运行时合成。

## 功能

- 🗺️ **宣纸战略地图**：二十八座城池、十二州水印、黄河长江、山脉关隘与势力色版图，Flame 绘制并支持点击选中
- 🏯 **五方势力**：魏（曹操）、蜀（刘备）、吴（孙权）、袁（袁绍）、董（董卓），各有城池、名将与初始钱粮
- 🗓️ **月回合制**：每城每月一条指令；结束本月后 AI 势力行动，再统一结算钱粮、触发事件并推进月份
- 🏛️ **内政六令**：开垦、招商、治安、征兵、训练、修城，农业 / 商业 / 治安 / 人口 / 训练 / 城防环环相扣
- 👤 **人事系统**：任命太守提升内政与守城，登用在野名士；破城后敌将有几率归降
- 🛡️ **兵种相克**：步兵克骑兵、骑兵克弩兵、弩兵克步兵；水军不参与克制，但在水乡战力大增
- ✨ **武将技能**：神武、铁壁、火计、治世、疾行五种技能，名将按特长获得，参与战斗与内政结算
- 🤝 **外交纵横**：在「势力」面板遣使，停战六月、联姻两年或劝降弱小势力；盟约期间玩家与 AI 均不可互相进攻
- 💾 **存档续战**：自动存档 + 三个手动槽位，首页可继续征战，三端通用
- ⚔️ **攻城战**：强攻、固守、火攻、突袭、撤退五种战术，士气、训练、统率、武力、智力、地形、兵种与城防共同决定胜负，另有阵前单挑
- 🤖 **AI 争雄**：AI 会开垦招商、征兵训练、择弱出兵、登用名士，难度越高越具侵略性
- 📜 **战报**：按月记录内政、战斗与随机事件，可筛选只看我方
- 🎲 **随机事件**：丰收、蝗灾、疫病、流民、民变、商队、名将来投
- 🏆 **胜负判定**：占尽天下城池即一统山河，失尽城池则霸业成空
- 🎯 **三档难度**：悠闲 / 争雄 / 霸业，影响 AI 收入与出兵阈值
- 🎵 **运行时音频**：七种战鼓号角音效与古筝五声音阶循环，可分别关闭；应用进入后台自动暂停
- ⚙️ **逻辑刷新率**：30 / 60 / 120Hz 三档可选（默认 60Hz），地图动画按固定步长推进
- ⚡ **渲染与启动优化**：地形、城池徽记与选中装饰分层缓存，内政等非视觉变更不重绘地图；选中脉冲数秒后自动停帧；音效与背景音乐后台合成，窗口、日志与偏好并行初始化
- 🧱 **结构清晰**：势力统计单遍汇总、外交成算批量计算，月度事件、城池名册、面板骨架与页面构件各自独立，首页、战斗页与各面板只保留状态与编排
- 🖥️ **自适应布局**：地图居中，信息卡悬浮在地图上方或左右两侧，按钮统一在下方；窄屏手机自动横屏全屏
- 🌓 **深色模式、简体中文**：Windows 优先 Microsoft YaHei UI，Web 使用 soup_fonts 思源黑体
- 🧾 **日志**：按天写入用户目录，保留 7 天，单个文件超 5 MB 自动轮转，设置页可查看与复制
- 🚀 **三端发布**：Gitea Actions / GitHub Actions 手动选定 Tag 构建 Android、Windows、Web 与 Release

## 开发

```bash
flutter pub get
flutter analyze
flutter test
```

构建产物由 CI 生成：在 GitHub Actions / Gitea Actions 手动运行 `build` 工作流并选中 `v*` Tag，按该 Tag 版本构建 Android / Windows / Web 并发布 Release；运行 `main` 则产出预览产物。音频运行时合成、Web 字体来自 soup_fonts，仓库不存放字体与音频文件。本地无需安装 Android SDK 等大型工具链。

## 日志位置

- Windows：`文档/FlutterThreeKingdoms/logs/app_yyyyMMdd.log`
- Android：应用外部存储目录下的 `FlutterThreeKingdoms/logs/`
- Web：仅保留内存日志，可在设置页查看与复制

## 目录结构

```
lib/
├── game/       剧本数据、回合控制器、内政与外交指令、战斗引擎与月度事件
├── flame/      Flame 战略地图组件与游戏入口
├── pages/      首页、对局页、战斗页、设置页、玩法说明与通用组件
├── services/   日志、偏好存储、音效与音乐合成
├── providers/  设置状态
├── models/     势力、城池、武将、战斗、战报与难度
├── theme/      配色、地图底图绘制
└── utils/      常量、格式化、布局、横屏与窗口初始化
```
